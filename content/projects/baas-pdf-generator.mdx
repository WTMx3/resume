The PDF Generator Service accepts structured sections, assembles a print-ready HTML document, renders it as an A4 PDF, and uploads the finished artifact to Amazon S3, Cloudflare R2, or another S3-compatible object store.

## What I built

- Designed a small Express API for document-generation requests.
- Implemented reusable cover and content-page layouts for structured project data.
- Integrated Puppeteer and Chromium for predictable server-side PDF rendering.
- Added S3-compatible object storage and public file URL responses.
- Containerized the service for repeatable builds and deployment.
- Added temporary-file cleanup and environment-driven configuration.

## Engineering focus

The service demonstrates document rendering, cloud storage integration, short-lived file management, container packaging, and the operational concerns involved in exposing a rendering endpoint safely.
