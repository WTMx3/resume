Listings+ is a responsive property-discovery application designed to make home search feel conversational. A guided request flow captures market, contact, and preference data, then coordinates with configurable search and CRM services to present useful listing results.

## What I built

- Created a natural-language property search flow with city autocomplete and structured preference capture.
- Developed responsive listing cards, comparison tables, image carousels, and property-detail experiences.
- Built server-action boundaries for search and lead-submission integrations.
- Composed accessible, reusable interface primitives with Radix UI, Tailwind CSS, and motion libraries.
- Prepared the Next.js application for Cloudflare deployment with OpenNext.

## Engineering focus

The project highlights product-oriented front-end engineering, third-party service integration, responsive information design, and careful separation between a public interface and private customer systems.

The linked repository is a sanitized public portfolio snapshot with customer identity, contact details, tenant identifiers, and production configuration removed.
